# React Hooks Checkpoint — GOMYCODE

Application de cinéma pour présenter ses films et séries préférés, construite avec les hooks React (`useState`).

## Composants

- `MovieCard` — affiche un film (titre, description, affiche `posterURL`, note).
- `MovieList` — parcourt la liste avec `map()` et affiche les `MovieCard`.
- `Filter` — filtre par **titre** et par **note** minimale.
- `AddMovie` — formulaire pour **ajouter un nouveau film**.

Chaque film possède : `title`, `description`, `posterURL`, `rating`.

```bash
npm install
npm start
```
